Questions people ask

Do the codes expire?

No. The link is stored inside the pattern itself, so the code works as long as the link does. If the website behind it goes down, that's the only way it stops.

Is it really free?

Yes. No account, no watermark, no trial. It's a static site with no server to pay for, so there's nothing to charge for.

Do you store what I type?

No. The code is made by JavaScript in your browser. Nothing you type or upload is sent anywhere. You can check the source on GitHub.

Can I change where the code points later?

Not with a static code, that's the tradeoff. If you think the link might change, point the code at a page you control and update that page instead.

Why won't my code scan?

Usually it's contrast. Keep the dots dark and the background light, leave the white border around the code, and don't print it smaller than about 2 cm. A big logo can also cover too much, so bump damage tolerance to Max.

Can I use them for business stuff?

Yes. Print them on menus, packaging, flyers, whatever. You don't need to credit anyone.
